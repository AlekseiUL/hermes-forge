# Positioning

Hermes Forge is an Anthropic-inspired local-first improvement control plane for Hermes Agent.

The shared idea is simple: agent improvement should be evidence-backed and eval-driven, not blind autonomous self-editing.

Hermes Forge applies that idea to a Hermes installation:

```text
Hermes runtime -> evidence -> findings -> proposal -> eval plan -> review -> apply gate
```

It is not affiliated with Anthropic and does not implement an official Anthropic system. It packages the principle for practical Hermes workflows.
